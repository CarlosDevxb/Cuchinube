Guia de uso y referencia de la API de Cuchipu Cloud.

ⓘ Esta API esta en version 1.0. Todos los endpoints devuelven JSON.
API Reference
Inicio Rapido
Autenticacion

🔌 GET /api/ping

Verifica el estado del servidor y devuelve la hora actual.

// Request GET /api/ping // Response 200 { "status": "ok", "timestamp": "2026-09-16T12:00:00.000Z", "uptime": "3600.50s", "region": "us-east-1" }

📊 GET /api/stats

Devuelve metricas de rendimiento del servidor en tiempo real.

// Request GET /api/stats // Response 200 { "cpu": "23.5%", "memory": "54.2%", "requests": 3420, "errors": 2, "latency": "12ms" }

⚙ GET /api/services

Lista todos los servicios desplegados con su estado actual.

// Request GET /api/services // Response 200 [ { "name": "API Gateway", "status": "active", "region": "us-east-1", "uptime": "99.99%" }, ... ]

🚀 Inicio Rapido

Sigue estos pasos para integrarte con Cuchipu Cloud.

Paso 1
Instala las dependencias: npm install
Paso 2
Inicia el servidor: npm start
Paso 3
Verifica el estado: curl http://localhost:3000/api/ping
Paso 4
Integra los endpoints en tu aplicacion cliente.
// Ejemplo con fetch const response = await fetch('/api/ping'); const data = await response.json(); console.log(data.status); // "ok"

🔐 Autenticacion

Los endpoints publicos no requieren autenticacion. Los endpoints privados requieren un token Bearer.

// Header requerido para endpoints privados Authorization: Bearer <tu_api_key> // Ejemplo const res = await fetch('/api/admin', { headers: { 'Authorization': 'Bearer sk-xxxx...' } });
⚠ Nunca expongas tu API key en codigo del lado del cliente. Usa variables de entorno.
